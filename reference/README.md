# Reference material (not deployed)

The site moved from WordPress on Hostinger to Cloudflare in October 2026. These folders keep the old site around as a reference for the revamp.

- `wordpress-live-2026-10-20/`: snapshot of the live dna4digital.com taken just before the move (page content, as-served HTML, PDFs, screenshots, media library). See its README for the page list.
- `wordpress-era-source/`: what this repo held while the site ran on WordPress: the page HTML and CSS that was pasted into WordPress, the React menu plugin, PHP snippets and hero images. The git tag `wordpress-final` marks that state.
