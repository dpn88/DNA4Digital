# dna4digital.com WordPress snapshot

Reference copy of the live WordPress site (Hostinger) taken before the move to Cloudflare.
Nothing here is deployed.

- `content/`: page and post body HTML from the WordPress API
- `rendered/`: full HTML as served, including theme markup and SEO meta
- `pdf/`, `screenshots/`: how each page looked (headless Edge, 1440px wide)
- `media/`: the public media library, by upload month
- `api/`: raw API responses
